# UI Testing

Use for browser workflows, responsive behavior, accessibility, visual state, or client/server interaction.

## Core

Record browser, viewport, build, role, and starting state. Verify visible behavior and persisted outcomes, then exercise the relevant error or recovery path. Treat network and console data as supporting evidence, not the user-facing oracle. Redact captured media.

## Optional Reference

For navigation, state, accessibility, responsiveness, concurrency, and compatibility coverage, load [UI-testing reference](../references/skills/ui-testing.md). Skip it for a single focused UI assertion.
