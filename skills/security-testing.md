# Security Testing

Use only for an explicitly requested review or authorized negative testing of a trust boundary.

## Core

Require a named target, permitted techniques, environment, identities, data rules, time window, stop conditions, and authorization. Otherwise perform passive review only. Prove minimum impact and stop on instability, unexpected real data, or scope ambiguity.

## Optional Reference

For threat mapping, security coverage, safe execution, evidence, and finding structure, load [security-testing reference](../references/skills/security-testing.md). Do not load it for ordinary functional testing.
