# Defect Analysis

Use when a test, user report, monitor, or model evaluation suggests incorrect behavior.

## Core

Confirm the expected result, reproduce from a clean state, minimize the sequence, and identify the earliest divergence. Separate product defects from environment or data failures. State root cause only when proven; otherwise give ranked hypotheses and the next discriminating check.

## Optional Reference

For systematic isolation, scope analysis, evidence handling, classification, and fix verification, load [defect-analysis reference](../references/skills/defect-analysis.md). Load severity policy only when classification is requested.
