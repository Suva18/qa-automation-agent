# Regression Testing

Use for validating a change, defect fix, dependency/configuration update, or release candidate.

## Core

Map the change to affected callers, data, integrations, permissions, and journeys. Verify changed behavior, its nearest boundaries, and a negative control. Distinguish product failures from flaky tests and environment failures. Report omitted coverage and residual risk.
