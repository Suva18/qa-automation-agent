# Meeting AI Testing

Use for capture, transcription, diarization, summaries, action items, search, retention, or meeting-assistant behavior.

## Core

Use synthetic meetings and consented voices. Preserve a reference transcript and annotated facts. Evaluate critical names, numbers, speakers, and derived artifacts separately. Test partial processing explicitly; missing content is not empty content.
