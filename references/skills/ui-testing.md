# UI Testing Reference

Load this only for broad UI planning or execution.

## Coverage

- Navigation, deep links, refresh, history, and protected routes.
- Loading, empty, partial, success, validation, error, retry, and offline states.
- Keyboard flow, focus, labels, roles, names, contrast, and zoom.
- Supported breakpoints, long/localized content, and browser matrix.
- Double submission, stale data, concurrent edits, interrupted uploads, and session expiry.

## Execution

Verify the primary journey and its persisted result, then alternate roles, boundaries, errors, and recovery. Separate functional, accessibility, usability, and visual findings.

## Output

Report exact visible behavior, expected behavior, environment, reproduction, and redacted evidence. Avoid pixel assertions for dynamic content unless a stable visual contract exists.
