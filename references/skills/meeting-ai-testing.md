# Meeting AI Testing Reference

Load this only for broad meeting-AI scenario design or execution.

## Scenario Matrix

- Audio: silence, overlap, accents, noise, bandwidth, reconnects, duration, and devices.
- Participants: joins/leaves, duplicate names, guests, speaker count, and consent.
- Language: supported languages, code-switching, names, acronyms, dates, and numbers.
- Artifacts: transcript timestamps/speakers, summaries, decisions, owners, due dates, and exports.
- Lifecycle: scheduling, admission, capture, processing, retry, deletion, retention, and reprocessing.
- Visibility: roles, workspace boundaries, private meetings, shared links, and revocation.

## Evaluation and Output

Use a consented reference transcript. Apply product-relevant transcript metrics and inspect critical facts separately. Report fixture, classification, configuration, metrics, fact accuracy, artifact results, lifecycle behavior, and privacy findings.
